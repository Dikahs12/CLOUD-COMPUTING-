# Cloud Computing Practice Using Vercel

## Overview

This repository contains a simple web application developed for the Cloud Computing course project at Universitas Muhammadiyah Sukabumi.

The project demonstrates how a static website can be deployed using the Vercel cloud platform. The entire application is built using a single HTML file that contains integrated HTML, CSS, and JavaScript, making it simple, lightweight, and easy to deploy.

---

## Project Objectives

The objectives of this project are:

- Understand the basic concept of Cloud Computing.
- Learn static website deployment using Vercel.
- Practice developing responsive web interfaces.
- Integrate HTML, CSS, and JavaScript into a single file.
- Publish a website using GitHub and Vercel.

## Deployment Using Vercel

1. Create a GitHub repository.
2. Upload the project files.
3. Sign in to Vercel.
4. Import the GitHub repository.
5. Configure the project using the default settings.
6. Click **Deploy**.
7. Wait until the deployment process finishes.
8. Access the generated public URL.
